# Извлечение результатов RAG

База результатов экспериментов из научных публикаций о Retrieval-Augmented Generation. Для каждой записи можно проверить значение и условия по публикации.

## Термины

**Результат метрики**  
Одно значение определённой метрики для конкретного эксперимента, набора данных, задачи и конфигурации RAG-системы или оценщика ответов. Место в публикации позволяет проверить значение и его связь с условиями.

**Оценщик ответа**

Метод, который выставляет готовому ответу оценку по заданному критерию, например по фактической обоснованности. Качество самого оценщика тоже может быть предметом измерения.

**Модель-судья**

Языковая модель, которую оценщик использует для выставления оценки готовому ответу по заданному критерию.

В результате её указывают как отдельное условие, если источник однозначно связывает модель с конкретным оценщиком в этом эксперименте. Если модель не указана, результат можно подтвердить при однозначной привязке значения к варианту эксперимента.

**Подтверждённый результат**

Результат метрики, для которого фрагменты статьи однозначно устанавливают значение, метрику и принадлежность к эксперименту и его варианту. Условия, оставленные авторами без уточнения, могут оставаться неизвестными, если привязка результата однозначна.

Для результата качества оценщика генератор ответов может оставаться неизвестным, если принадлежность к варианту эксперимента однозначна. Если авторы различают варианты по генератору, связь значения с этим вариантом требует источника.

**Фрагмент источника**  
Место на конкретной странице публикации, подтверждающее значение или условие результата. Это может быть ячейка таблицы с заголовками, область рисунка или фрагмент текста.

**Контекст таблицы или рисунка**

Подборка фрагментов публикации, которые помогают связать наблюдения из одного объекта с условиями эксперимента. Для каждого фрагмента сохраняется основание связи с объектом.

**Область таблицы**

Часть страницы конкретной версии PDF, занимаемая таблицей. У области есть страница и границы, а у таблицы может быть обозначение в статье, например `Table II`.

**Карта статьи**

Перечень обнаруженных областей таблиц, рисунков и разделов в конкретной версии PDF с их адресами и замечаниями о неполном обнаружении. Карта показывает, где искать материал для извлечения; она не подтверждает значения или условия экспериментов.

**Область действия условия**

Эксперимент, таблица, методы или группы методов, к которым авторы относят условие. Область действия может быть указана без перечисления отдельных методов, например «большинство бейзлайнов».

**Утверждение об условии**

Значение условия эксперимента, указанное авторами, вместе с его областью действия и местом в публикации.

**Подтверждённое условие**

Условие, для которого источник однозначно задаёт поле, значение и применимость к конкретному результату. Если применимые источники дают разные значения, условие остаётся открытым до разрешения противоречия.

**Неоднозначная привязка**  
Случай, когда место и исходное значение в публикации известны, а фрагменты статьи допускают несколько связей с условиями эксперимента или дают недостаточное основание для единственной найденной связи.

**Прогон извлечения**

Отдельная обработка определённой версии публикации по заданному плану с полученными результатами метрик, фрагментами источника и замечаниями. Намеренная повторная обработка, в том числе с изменённым планом или версией публикации, образует новый прогон.

**Прогон области**

Прогон извлечения для участка страницы, который указал оператор. Его результаты и замечания относятся к выбранной области и той же версии PDF.

**Попытка извлечения**

Одно выполнение этапа в пределах прогона извлечения. Повтор после сбоя или применение другой предусмотренной планом стратегии создаёт новую попытку того же прогона.

**Опубликованная версия результатов**

Неизменяемый набор подтверждённых результатов метрик и замечаний, доступный в общей библиотеке и выгрузке. Может отражать частичный охват публикации; границы охвата сохраняются вместе с набором.

**Черновик ручной проверки**

Предложение проверяющего для конкретного поля результата или замечания в закреплённой опубликованной версии. Сохранение черновика не изменяет версию и её выгрузку.

**Замечание извлечения**

Выявленный пробел, противоречие или неопределённость в извлечённых данных либо их привязке к условиям. Замечание может сопровождать полученный результат и не означает сбоя обработки.

**Эталон извлечения**  
Разметка публикаций для проверки полноты извлечения, точности значений, правильности связей с условиями и привязки к источнику.
