# ADR-0004: Граница применения LLM/VLM и контракт подключения сильной LLM поверх `assemble()`

Статус: принято 22 ноября 2026 года (4B-модель исключена из автовыпуска; плагин сильной LLM/RAG — в roadmap).

## Контекст

Для сложных таблиц с нестандартными подписями, прозы и графиков рассматривалось подключение локальных моделей через Ollama (`qwen3-vl:4b-instruct-q4_K_M`, а также подготовленные клиенты `granite-vision-4.1-4b` и `PaddleOCR-VL-1.6`). Перед включением в конвейер проведены контролируемые эксперименты на фиксированных выборках:

- **Таблицы (`qwen3-vl:4b`):**
  - Запрос на полную JSON-схему с координатами диапазонов оборвался по лимиту токенов в 10 из 18 вызовов (~60 с/таблицу) и дал `0` верных новых полей при `2` ошибках (модель записывала число ячейки в `metric`).
  - Упрощённый короткий запрос только на роли кандидатов убрал обрывы (30,7 с на 3 таблицы), но дал **14 ошибок из 42 ролей** (включая 4/4 описательных статистик в `P020`, помеченных как метрики качества, и ошибки на заголовках блоков в `P005` по 48 ячеек каждая). Прирост сверх детерминированных правил с контекстом составил **0/42**.
- **Графики (`chart-crop-probe`, 12 контрольных точек `test`):**
  - `qwen3-vl:4b` верно прочитала **6 из 6 напечатанных чисел** (включая растровый скан `P054 Fig. 4: 18.5×`) и дала `0` ложных на схеме-иллюстрации `P002 Fig. 1`, но **0 из 6** оценок по шкале без подписей, а на 4 из 6 напечатанных ошиблась в выборе оси (всего 2/12 полностью верных наблюдений).

## Решение

1. **Исключить локальную 4B-модель из автоматического выпуска 7 CSV.**  
   Детерминированное ядро + `Entity Passport` уже обеспечивает 89,23% Precision на `dev_gold` при 0 галлюцинаций чисел и полной локальной воспроизводимости.
2. **Зафиксировать безопасный контракт для подключения сильной LLM (14B–32B+ или облачное API) и RAG-слоя поверх `assemble()`:**
   - **LLM никогда не извлекает и не переписывает числа таблиц и их `box`** — `Observation` всегда приходит строго от парсера сетки.
   - **Один структурированный запрос на таблицу или секцию** (вход: шапка + 3–5 строк сетки + подпись + релевантные чанки из `article-text.json`).
   - **Выход LLM — только типизированные кандидаты `Assertion(field, value, Scope, evidence_id, verbatim_quote)`** (для закрытия открытых полей из `issues.csv`: `dataset`, `generator`, `evaluation_protocol`, `task`, либо для извлечения чисел из прозы для оставшихся ~5% статей без табличных результатов).
   - **Обязательный детерминированный верификатор перед `assemble()`:** код проверяет, что `evidence_id` существует, `verbatim_quote` буквально содержится в тексте этого фрагмента, а значение не конфликтует с подтверждённым правилом Уровня 1. Неподтверждённые гипотезы остаются в `issues.csv`.
3. **Для графиков:** использовать ансамбль из 2–3 VLM (`qwen-vision`, `granite-vision`, `paddleocr-vl` — клиенты уже в `rag_mvp/strategies/`) с правилом консенсуса по числу и серии + отдельной геометрической проверкой осей; до калибровки осей держать графики в режиме черновиков и ручного подтверждения в вебе.

## Последствия

- Текущий релиз гарантирует нулевые галлюцинации и 100% воспроизводимость без внешних ключей и GPU.
- Как только в контуре появляется сильная LLM (или RAG-индекс по `article-text.json`), её подключение не требует переписывания ядра, хранилища, экспорта CSV или интерфейса — достаточно одного нового генератора `Assertion` с тем же тест-гейтом (`dev_gold` + `P020 = 0` + `check_submission.py`).
