## Где связь сейчас теряется

Поиск контекста D007 уже собирает доказательства из нескольких подписей. `extract_table_assertions` возвращает `table_default` с исключёнными методами и `method_exception` с основным и дополнительными источниками. Существующая проверка на реальном PDF подтверждает это для Tables 2, 7 и 8. Однако штатный `interpret_grid` идёт через `bind_article_context`, который вызывает `extract_condition_assertions` и получает только поддерживаемые шаблоны прозы. При локальной диагностике с исходными текстовыми фрагментами D007 и минимальными тестовыми `ReadTable` для всех трёх адресов извлекатель подписи вернул по два ожидаемых утверждения, а связыватель вернул пустые утверждения. Это проверка стыка стадий. Покрытие реальной сетки D007 этим опытом не измерено. `ConditionAssertion` ядра уже хранит адрес таблицы, ссылку на цитату и дополнительные ссылки. `match_condition` умеет подтверждать единственное применимое значение и оставлять несколько значений в замечании. Текущая ветка уже подтверждает локальные привязки D005/P003 на сохранённых сетках. Для D007 нужно донести область действия и источники, которые соседний этап уже вычислил. ## Одна доработка

В `bind_article_context` передавать подтверждённый контекст в существующий `extract_table_assertions`. Преобразовать его два вида условий в уже понятные ядру утверждения для конкретных методов текущей таблицы. Общее условие применять к явно принадлежащим этой таблице строкам вне исключений, специальное — только к явно сопоставленному методу. Для D007 проверка должна учитывать авторскую метку сноски у `Self-RAG∗`, сохраняя её в оригинале. В `condition_sources.generator` сохранить цитату о модели и подтверждения её применимости. Для исключения без доказанной связи с соседней подписью сохранить число как замечание с открытым генератором. Если два действительно применимых источника расходятся, передать оба в существующее разрешение конфликта.
