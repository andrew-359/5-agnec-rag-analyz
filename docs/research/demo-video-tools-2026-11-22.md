# Запись демонстрации RAG на Linux

22 ноября 2026 года. Для первого короткого ролика стоит попробовать **Capturia** на X11. Она объединяет захват окна, автоматическое приближение по курсору, оформление и монтаж. Для повторных записей одного маршрута после изменений интерфейса подойдёт **Playwright**, который уже используется в проекте. Возможности и доступность сборок сверены по источникам проектов. Пробную запись этими инструментами в рамках сравнения не делали.

README указывает PipeWire и `xdg-desktop-portal`. В GitHub-релизе **2.1.0 от 12 сентября** есть AppImage, `.deb`, `.rpm` и Arch-пакет. Для программного монтажа готовых дублей можно добавить **Revideo**. MIT-движок рендерит сцены из TypeScript с видео, анимацией и текстом. У репозитория нет GitHub-релизов, последний коммит на `main` датирован 15 июля. Для первого ролика достаточно редактора Capturia. [Движок](https://github.com/midrender/revideo#readme) · [Релизы](https://github.com/midrender/revideo/releases) · [Коммит](https://github.com/midrender/revideo/commit/b5de67a009a55aa2768a1e178b0446b2479a0b4e)

Для первого дубля можно взять готовый выпуск D001 и пройти маршрут за 45–60 секунд. Открыть результаты, выбрать `.422` в основной оценке, показать подсвеченную ячейку на PDF-странице 6, вернуться к результатам и скачать комплект CSV. Для повторяемого дубля переиспользовать шаги браузерной проверки, сохранить размер 1920×1080 и дождаться отрисовки PDF перед следующей сценой.
