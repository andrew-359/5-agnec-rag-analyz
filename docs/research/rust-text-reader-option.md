## Предложение для следующего среза

Добавить явную стратегию `rust-pdfium` в существующий реестр общего текста. Один адаптер запускает имеющийся бинарник и читает его JSON штатным парсером с проверкой SHA-256. Путь к бинарнику и совместимой библиотеке задаётся в конфигурации локального исполнителя. Оператор выбирает её через `--text-reader`; `auto` сохраняет прежний выбор. Граница стратегии заканчивается сохранённым текстом. Привязка, сверка и выпуск используют действующие правила. [Как CLI передаёт ридер](../../README.md#cli-прогонов) · [Граница Python-исполнителя](../../rag_mvp/article_stage_extraction.py#L88)

На первом контроле сравниваем два текстовых входа на одной сохранённой сетке. Кроме CSV, проверяем цитаты, рамки и порядок чтения. ID фрагмента включает хеш PDF, страницу и порядковый номер. При разном разбиении один ID может обозначать разные фрагменты, поэтому основание надо открывать в артефакте той попытки, в которой оно получено. Допуск в `auto` зависит от качества источников и замера полного прогона.
