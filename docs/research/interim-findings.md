### Таблицы

**Сетку можно прочитать хорошо и всё равно потерять результаты при привязке.** В раннем замере 12 таблиц из 10 статей в сохранённых сетках совпало 696 из 856 чисел, а в CSV — 396 строк по основному ключу и 378 при проверке ещё и `top-k` и единицы. В последующей проверке D001 Table 1 нативный TableFormer дал 252 из 252 записей, а OCR + TableFormer прочитал 236 чисел из 252, но не подтвердил ни одной связки из-за шапки. Для оценки стратегии считаем отдельно прочитанное число, привязку к условиям и адрес источника. ### Qwen после штатного разбора

**На P003 точечный запрос помог заполнить конкретное условие.** Для строки Fixed-1 RAG правила пропустили `retrieval top-k=1`. Qwen нашёл значение по готовым фрагментам, но в первом ответе убрал переносы строк из двух цитат. Во втором запросе он выбрал три ID, а код взял текст цитат из сохранённых фрагментов. Все три прошли ручной контроль. Это результат на одной строке P003 из test с локальной ручной разметкой. [Контроль по PDF](../../.scratch/qwen-text-conditions/p003-control.md) · [Ответ и сверка](../../runs/p003-qwen-row.NOY5kdHr/source-ids/report.json)

**На четырёх контролях из dev подтверждённой прибавки пока нет.** Qwen правильно нашёл `top-k=5` у ThreadRAG в D001 и Llama 3.3 70B у Prompt-A в D005. Оба условия уже есть в штатном разборе. В D009 для Self-RAG модель заметила исключение в объяснении, но вернула Qwen2.5 вместо Llama-2-13B. Для FLARE значение совпало с `dev_gold`, однако цитата про «большинство бейзлайнов» не подтверждает конкретный метод. Эталон подключаем после извлечения. Отдельно проверяем совпадение с эталоном и применимость источника к строке. ### Что проверяем дальше

- Основой остаются штатные ридеры и правила. Qwen пробуем на конкретном замечании после извлечения. Код передаёт адрес строки и копирует цитаты по выбранным ID, оператор сверяет применимость. Следующий показатель для проверки — сколько замечаний удаётся закрыть с правильными источниками и сколько времени это экономит по сравнению с открытием PDF вручную. [Роль модели](../plan.md#роль-модели)
- Для графиков интересен контроль на растровой панели, где обычный ридер оставил пропуск или не разобрал легенду. На одной и той же области считаем новые правильные значения, ошибки серий и лишние предложения. Для полного LLM-прогона сохраняется отдельная исследовательская гипотеза на одинаковых статьях. [Идея двух режимов](../TO_THINK.md#два-режима-извлечения)
