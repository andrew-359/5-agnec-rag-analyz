## Что чинить после рефактора

Оба числовых случая показывают ограниченность комбинаций привязки, а не необходимость менять ридер по умолчанию. D005 требует локальной области приложения, dataset из абзаца и модели для Prompt-A/B/C/D. P003 требует модели из группы строк и шапки metric → dataset. Единый принцип — собирать условия из нескольких адресованных источников, не требовать единственного фиксированного порядка шапки. Перед изменением сравнить с новым рефактором: возможно, часть правил там уже реализована.

Контроли против ложного улучшения: не перенести основную Llama-3.1 на D005 Appendix A; не приписать P003 Table 1 пять seed и статистику Table 3; не считать OC@0.8 retrieval top-k; не подменить неизвестные поля догадками ради ненулевого CSV. После исправления повторить те же PDF и проверить число, связи и источник отдельно. Увеличение числа строк само по себе не приёмка.

Ближайший безопасный следующий шаг — расширить поиск на изображения с наложенным OCR-слоем и малые фрагменты, чтобы закрыть положительный числовой mixed-контроль. Изменение продуктового кода пока отложено до объединения большого рефактора.
