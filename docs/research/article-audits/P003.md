# P003. Контроль привязки прочитанной метрики

Test, URGen, цифровой PDF с растровыми иллюстрациями. Контроль взят из сохранённого полного прогона. В Table 1 на физической странице 6 прочитана сетка, но опубликованных результатов из таблицы нет.

| Что сверить | Что показывает источник |
| --- | --- |
| Конфигурация | Группа строк Llama-3.1-8B, метод URGen (Ours) |
| Набор и метрика | TED, Accuracy (%) с направлением улучшения вверх |
| Исходное значение | `80.40%`, стр. 6, Table 1. §4.5 на той же странице повторяет число |
| Протокол | §4.4 определяет Accuracy как долю правильно выбранных ответов. Пять seed в этом разделе относятся к отдельному сравнению фиксированной глубины из Table 3 |
| Фактический выход | `ambiguous-binding` с исходным значением, шапкой `Accuracy (%) ↑ → TED` и областью ячейки. Поля условий и их источники пусты |

Проверка после исправления привязки должна получить одну связанную запись для этого ключа и открыть исходную ячейку. Две соседние метрики того же ряда, OC@0.8 и ECE, остаются отдельными результатами. Провал чтения таблицы здесь уже исключён сохранёнными числом и рамкой.

При поиске естественного смешанного контроля P003/стр. 8, P017/стр. 7 и P066/стр. 8 проверены визуально и по текстовому слою. На этих страницах растровые иллюстрации соседствуют с цифровыми таблицами. P024/стр. 16 содержит таблицу внутри скриншота примера, её показатели относятся к показанному документу.
