# D002 — MoRSE для вопросов по кибербезопасности

MoRSE использует структурированный поиск с переходом к неструктурированному при отсутствии контекста. Авторы сравнивают ответы на общие, многошаговые и CVE-вопросы. Все 17 физических страниц синтетического скана без текстового слоя просмотрены с OCR, ключевые таблицы и расхождения сверены по изображениям. [PDF участника](../../context/RAG_ВИНИТИ_участникам_2026-11-20/dev/D002.pdf).

## Что дал прогон

- Сохранённый CLI-бенчмарк от 21 ноября (`unstructured`) отклонил `--table II` как нецелочисленный аргумент, код 2. Прямой вызов Python с `II` завершился с кодом 0, записал `grid: null`, ноль ячеек и результатов и одно замечание о ненайденной таблице с подписью. В CSV только заголовок, совпадений 0 из 60. [Попытки](../../../runs/benchmark-2026-11-21.hSazlU/attempts.json) · [Отчёт извлечения](../../../runs/benchmark-2026-11-21.hSazlU/D002-p8-tII-unstructured/run.json).

Табличный детектор сохранил 50 из 60 ожидаемых чисел при сравнении значений с учётом кратности. В сырой сетке имена MoRSE и GPT-4 слиты, а `0.90` и `0.74` лежат в одной ячейке. Эти артефакты позволяют диагностировать OCR, привязку к строкам и связь с подписью.
