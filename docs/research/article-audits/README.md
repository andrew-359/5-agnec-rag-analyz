## Как сверить новый прогон

1. По карточке найди нужный PDF, эксперимент и адрес источника. Карта охватывает статью целиком, включая другие метрики, рисунки, текст и приложения.
2. Проверь обнаружение источника, затем чтение чисел и их привязку. Для таблицы выпиши, сколько адресов найдено, сколько числовых значений прочитано и сколько записей совпало по метрике, условиям, значению и источнику. Ожидаемые пропуски из gold учитывай отдельно.
3. При расхождении открой конкретную страницу PDF. Проверь подпись, шапку, ячейку и цитату с условием. Для приблизительных значений графиков возьми точность из примечания gold.
4. Сохрани дату, версию кода, режим, стратегию и ссылку на артефакты. Результаты CLI и RabbitMQ относятся к своим запускам. Команды и способы открыть артефакты описаны в [локальных прогонах](../../../runs/README.md) и [инструкции RabbitMQ](../../../web/README.md#разобрать-статью-через-rabbitmq).
