Манифест записывается перед созданием ZIP и атомарной установкой версии, поэтому второй запрос принят как минимум за **134,932 с** до установки первой версии. При обработке пары в выделенной очереди наблюдались один потребитель, 25 готовых сообщений и одно неподтверждённое. К концу замера очередь опустела.

Во всех версиях API подтвердил связь манифеста с соответствующим `run_id` и открыл результат R235 и ячейку S240 для ThreadRAG / LLaMA3-8B-Instruct / HotpotQA / EM `.422` из Table 1 на PDF-странице 6. Версионный адрес PDF вернул тот же SHA-256, что у загруженного файла. После замера Chromium открыл по прямым ссылкам каждую закреплённую версию, отрисовал страницу 6 и показал подсветку ячейки. Во всех выпусках получено по 288 результатов с частичным охватом. Table 4 осталась без сетки, а Tables 3, 6–8 остались без подтверждённых результатов. Чекер ВИНИТИ записал предупреждения с кодом 2. Стенд работал на Intel Core i7-14650HX с Node 24.21.0, Python 3.12.3, Docling 2.151.1 и Torch 2.8.0 CPU. Hono, один Python-воркер и отдельный контейнер RabbitMQ 4.2 использовали выделенную очередь `rag.d001-load.local-01` и пустые каталоги данных. D001 был загружен один раз. Построение карты заняло 1,867 с до замеров. На машине выполнялись и другие задачи, включая независимый E2E-прогон. Длительности относятся к этому стенду и одной серии из трёх запусков.

Полные карточки, манифесты, ответы на запросы источников, снимки Chromium, отчёты чекера и журналы сохранены локально в `runs/load-baseline/d001-local-01/`. Сводка находится в `measurement/baseline.json`. [Команды воспроизведения](../../runs/README.md#замер-полного-прогона-d001-на-одном-воркере)
