# Что обсудить по интерфейсу

Первый экран позволяет выбрать число и сразу увидеть его место в статье. Проверять решения удобно на D001, где несколько одинаковых чисел встречаются в разных столбцах. Для состояния с ошибками подойдёт сохранённый прогон OCR по D013, когда он будет готов.

| Тема | Что решить | Стартовый вариант |
| --- | --- | --- |
| Источник справа | Сколько контекста нужно в приближении и когда открывать статью во весь экран? | По умолчанию показываем ячейку и соседние строки. Путь по заголовкам остаётся над изображением. Полную страницу можно развернуть. |
| Таблица результатов | Какие столбцы обязательны и как группировать сотни строк? | Оставляем метод, генератор, датасет, метрику и число. На узком экране генератор доступен в деталях выбранной строки. Проверяем, нужна ли группировка по эксперименту. |
| Ссылки из условий | По каким полям нужно открывать отдельный фрагмент источника? | Начинаем со значения. Когда CLI отдаст координаты заголовков, добавляем переходы из метода, датасета и метрики к их собственным фрагментам. |
| Сравнение | Как выбрать два результата и объяснить несовпадение условий? | Две закреплённые строки с проверкой датасета, метрики и протокола. Если условия расходятся, рядом с числами показываем причину. |
| Замечания | Какие ошибки пользователь должен исправлять сам и где ему нужен контекст? | Для первого среза открываем замечание вместе с фрагментом. Затем решаем, нужны ли подтверждение и правка поля с историей изменений. |
| Загрузка и история | Как пользователь возвращается к прогону после обработки? | Обсуждаем экран со статусом задания, ссылкой на готовую статью и прошлые прогоны, когда подключим передачу PDF в CLI. |
| Визуальный ритм | Что считывается первым на экране ноутбука? | На демо проверяем, видны ли выбранная строка, число и подсветка одновременно. По этому сценарию выбираем плотность таблицы, ширину правой панели и размер текста. |

При обсуждении демо полезно пройти один маршрут вручную. Найти результат → сверить его с ячейкой → развернуть страницу → вернуться к прежним фильтрам. Следующий маршрут добавляет выбор двух результатов и проверку условий сравнения.
