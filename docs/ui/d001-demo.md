# Идея первого демо интерфейса на D001

Первым показываем готовый пример D001. Зритель сразу может проверить число из каталога по оригиналу статьи.

1. **Открыть готовый пример.** В каталоге уже видны результаты D001 для HotpotQA и метрики EM. Можно сразу нажать на `0.422` в строке ThreadRAG.
2. **Нажать на число.** Справа открывается режим **«Фрагмент»**. Просмотрщик приближает ячейку `.422` в Table 1 на странице 6 и подсвечивает её. В кадре по возможности оставляем название строки и заголовок столбца, чтобы было видно, к каким условиям относится число.
3. **Переключиться на всю страницу.** Кнопка **«Вся страница»** показывает страницу 6 целиком с выделением той же ячейки. Кнопка **«Фрагмент»** возвращает приближение к ней. Повторный клик по другому числу открывает его фрагмент.

Для первого демо используем сохранённый прогон D001. Сценарий готов, когда его можно пройти с первого экрана без загрузки файла и ручного поиска по PDF, а выделение в обоих режимах указывает на одну и ту же исходную ячейку.
