# Покрытие каталога ВИНИТИ

В [каталоге](../../.scratch/viniti-functional-acceptance/ui-test-cases.md) 130 ID. Один автотест может проверить несколько критериев, а параметризованный сценарий даёт несколько запусков в Allure. Число выполненных тестов и число закрытых ID считаются отдельно.

На указанных уровнях автоматизированы **69 критериев**, частично покрыты **33**, отдельная проверка нужна для **28**.

Браузерный набор запускает React и PDF.js с синтетическим PDF и управляемыми ответами HTTP. Серверный набор вызывает реальные маршруты Hono, обработку черновиков SQLite и движок сравнений. Контракт выпуска создаёт реальные ZIP и CSV из синтетического артефакта и подставляет результат внешнего чекера. Полный локальный Node-прогон дополнительно использует D001 и официальный чекер из комплекта участника.

## Наборы для функциональной регрессии

| Вид | Что запускается |
| --- | --- |
| Модульные и компонентные | Python проверяет преобразования таблиц, OCR-сетки, правила привязки и графики. Обработчики модельных ответов проверяются на локальных ответах, включая таймаут и неправильный формат. |
| Интеграционные API | Hono принимает синтетический PDF, вызывает реальный Python для построения карты и после повторного открытия хранилища возвращает тот же PDF. Дополнительно проверяются сравнения, SQLite-черновики и версия экспорта. |
| Данные и предметная сверка | Синтетический выпуск проверяет ссылки CSV и целостность ZIP. Локальный набор сверяет оригиналы и сохранённые результаты, в том числе 16 значений D005 и контрольные ячейки P003. |
| Очередь и воркеры | Локальный набор Figure 5 загружает D001 и запускает Python через RabbitMQ. Он проверяет доставку, результат vector-bar, неприменимость и отказ модельного ридера на контролируемом ответе. |
| UI и сохранённый E2E | 33 быстрых Selenium-проверки и 6 локальных проверок на сохранённых выпусках. |

## Расхождения текущего React с каталогом

- NAV-03 и часть RES-04. Библиотека ищет по названию и имени файла. Поиск результатов сопоставляет метод, генератор, датасет, метрику и число. Номер таблицы в поиск сейчас не входит.
- RES-12. В React смена любого выпадающего фильтра снимает выбранный источник. Каталог требует сохранять источник при совместимом фильтре.
- MAP-07 и MAP-08. При сворачивании карты PDF остаётся открыт. Для отдельного якоря нет сохраняемого адреса.
- REV-06. Сохранённый черновик восстанавливается. Несохранённый ввод защищает подтверждение ухода.
- EXP-04. Контрольная ячейка паспорта открывается без прежнего поискового запроса, даже если запрос совместим.
- SRC-14 и UX-04. В текущем React один макет. CI-06/07/08/10 отложены вместе с Coolify.
